# HighlightCursor

<!-- Plugin description -->

## What's HighlightCursor?

This is an IntelliJ extension that allows you to change the cursor color.

[View this plugin on JetBrains Plugin Store](https://plugins.jetbrains.com/plugin/26743-highlightcursor)

## Usage

### Settings Location

`Settings > Tools > HighlightCursor`

### Steps

1. Choose your desired color to change the cursor color.
2. If you want to change the cursor color in Vim, enable **"Enable Vim customize settings"** and select your preferred
   colors.
    - Currently, only the colors for **Insert Mode** and **Other Modes** can be customized.

## Supported Platforms

- Linux
- Windows

## Compatibility

- Works with Vim
